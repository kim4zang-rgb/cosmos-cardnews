# cosmos. 카드뉴스 자동화 파이프라인 — 운영 방식

이 문서는 실제로 채택한 운영 구조를 정리한 것입니다 (claude.ai 로컬 플랜 파일과 별개로, 이 저장소를 통해 어느 PC에서든 확인 가능하도록 여기에 남겨둡니다).

## 핵심 결정: 비용 최소화를 위해 "로컬 2-PC + 구독 사용량" 방식 채택

세 가지 실행 방식을 비교했고, **로컬 방식을 기본으로 채택**했습니다:

| | 로컬 2-PC (채택) | Claude 클라우드 루틴 | Anthropic API 직접 호출 |
|---|---|---|---|
| 추가 비용 | 구독 한도 내 $0 | 불명확 (검증 필요) | 게시물당 약 $0.2~1, 하루 12개×월이면 10~50만원 |
| 상시 자동 실행 | ✗ (해당 PC가 켜져 있어야) | ✓ | ✓ |
| 사용량 초과 위험 | 있음 (Pro/Max 한도) | 있음 | 없음 (쓴 만큼만 과금) |

**운영 원칙**: 평소엔 로컬 2-PC 방식(무료)으로 운영하고, Pro/Max 사용량 한도에 자주 걸리면 그때 일부 또는 전체를 API 방식으로 전환한다.

## 실행 환경

- **집 PC / 사무실 PC** 두 곳 모두에 이 저장소를 클론해두고, Claude Code(구독 포함)로 작업.
- 동기화는 git으로: 작업 시작 전 `git pull`, 끝나고 `git add -A && git commit && git push`.
- 두 번째 PC 최초 설정 방법: [second_pc_setup.md](second_pc_setup.md)

## 아이템 입력 경로 (변경 없음)

- **경로 A**: 매일 아침, 그날 켜져 있는 PC에서 Claude Code를 열고 "오늘 아이템 스캔해줘"라고 요청 → `config/subjects.json`의 13개 분야 기준 트렌드 조사 → 후보 2~3개 중 선택.
  - (참고: Windows 작업 스케줄러로 이 트렌드 스캔 자체를 완전 자동화하는 것도 검토했으나, `claude` CLI의 정확한 비대화형 실행 명령을 아직 검증하지 못해 보류 — 확인되면 이 섹션에 추가 예정.)
- **경로 B**: 대표님이 아무 때나 "이 뉴스로 카드뉴스 만들어줘" 식으로 아이템을 직접 지정 → 트렌드 스캔 생략하고 바로 본문 작성 단계로.

## 이후 단계 (경로 A/B 공통)

1. 본문 작성 — [write_copy_guidelines.md](write_copy_guidelines.md) 규칙 따름
2. 카드뉴스 조립 — [../templates/README.md](../templates/README.md)의 템플릿(Cover/Point/Stat/Closing) 사용, 배경 이미지는 `tools/fetch_bg_image.py`로 검색
3. 검수 — 완성된 캔버스 링크 + 캡션을 확인 후 승인
4. 배포 — 인스타그램 자동 게시는 별도 기술 스파이크 필요 (Graph API용 공개 이미지 호스팅 방식 확정 전까지는 수동 게시)
