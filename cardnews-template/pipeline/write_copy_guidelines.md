# cosmos. 카드뉴스 — 본문 작성 가이드

경로 A(트렌드 스캔 후 선택)든 경로 B(직접 아이템 지정)든, "아이템명 + 참고 자료"만 있으면 이 가이드에 따라 (1) 카드 스크립트, (2) 인스타 캡션을 작성한다.

**중요 (2026-08-27 확정)**: 카드 스크립트와 인스타 캡션은 **한 번에 같이 작성**한다. 스크립트만 먼저 쓰고 캡션을 나중으로 미루지 않는다 — 아이템 하나가 정해지면 두 산출물을 항상 동시에 완성해서 내놓는다.

## 입력

- 아이템명 (예: "우주에는 왜 소리가 없을까")
- 참고 링크/메모 (경로 A는 트렌드 스캔 검색 결과, 경로 B는 대표님이 준 자료)

## 출력 1 — 카드 스크립트

**4대 규칙 (2026-08-27 확정, 같은 날 2차 수정)**:
1. **표지는 후킹이 강한 문구** — 정보 전달보다 궁금증 유발이 우선.
2. **내지는 팩트 중심으로 술술 읽히게** — 의견이나 수식어보다 확인된 사실을 문장으로 풀어 쓴다.
3. **슬라이드 1장당 텍스트 제한 없음** — 할 말이 많으면 많아도 된다. (2줄 제한 규칙은 폐기됨 — 팩트를 억지로 잘라서 부자연스러워지는 것보다, 자연스러운 문장으로 완결되게 쓰는 것이 우선이다.)
4. **카드 수 제한 없음** — 1장이어도 좋고 10장이어도 좋다. 아이템이 필요로 하는 만큼만 쓴다. (5~8장 규칙은 폐기됨)

`templates/README.md`의 슬라이드 구성(Cover 1 + Point N + Stat 0~1 + Closing 1)에 맞춰 아이템을 쪼갠다 — Point 개수는 아이템의 사실 개수에 맞춘다.

- **Cover 헤드라인**: 궁금증을 자극하는 훅. `<br>`로 끊어서 짧게, 한 줄 6~9음절 (76px 폰트에서 936px 폭에 안전하게 들어가는 기준).
- **Cover 서브카피**: 생략 가능 — 표지는 훅 헤드라인만으로 승부하는 것을 기본으로 한다.
- **Point 슬라이드**: 하나의 슬라이드 = 하나의 사실. 그 사실을 완결된 문장으로 자연스럽게 쓴다 (길이 제한 없음, 다만 한 슬라이드에 여러 사실을 욱여넣지는 않는다 — 사실이 여러 개면 슬라이드를 늘린다).
- **Stat 슬라이드(선택)**: 임팩트 있는 숫자나 사실이 있을 때만 추가. 숫자는 라틴 문자/숫자로 (Syne 폰트가 한글 미지원).
- **Closing**: 마무리 문장을 자연스럽게 새로 쓴다. 태그라인("13 SUBJECTS, RELEASED DAILY")과 CTA 두 줄("저장하고 다시보기" / "팔로우하고 다음 주제 받기")은 브랜드 고정 문구이므로 건드리지 않는다.

**주의**: 실제 사실 관계가 필요한 통계·숫자는 참고 자료에서 확인된 것만 쓴다. 확인 안 된 수치를 그럴듯하게 지어내지 말 것 — 확실하지 않으면 Stat 슬라이드 자체를 생략한다.

## 출력 2 — 인스타 캡션

톤: **캐주얼한 반말체, 장난스럽거나 슬랭 남발은 지양** (대표님 확정 사항 — "장난스럽게"는 취소하고 "캐주얼하게"만 유지).

**중요 (2026-08-27 3차 확정)**: 카드는 훑어보기 좋게 가볍게 유지하는 대신, **깊이는 캡션이 담당한다.** 카드에 못 담은 배경·맥락·구체적 수치·관련 사실을 캡션에서 풀어준다 — 카드 내용을 그대로 반복하거나 스포 안 하려고 얕게 요약하지 말고, 자세한 정보를 원하는 독자가 캡션만 읽어도 충분히 만족할 만큼 실질적인 정보를 담는다. 참고 자료에서 확인된 사실만 쓰고, 확인 안 된 내용은 넣지 않는다 (스크립트와 동일한 원칙).

구조:
1. 훅 — 카드 표지와 비슷한 궁금증 유발 문장
2. 본문 2~4문단 — 배경, 맥락, 구체적 수치, 관련 사실까지 포함해 실질적인 정보를 제공. 카드가 다루지 못한 디테일을 여기서 채운다.
3. CTA 한 줄 — 저장 + 팔로우 (또는 카드로 유도하는 한 줄)
4. `cosmos.magazine`
5. 해시태그 3개 내외 (`#cosmos` + 주제 관련 2개) — 대량 해시태그 블록 지양. 인스타그램 알고리즘이 해시태그보다 참여도(저장·공유) 기반으로 바뀌어서, 요즘은 검색 유입용 소수 키워드만 다는 게 트렌드.
6. 이모지는 기본적으로 넣지 않는다 (로고 가이드의 "심볼 미사용" 원칙과 통일 — 필요하면 대표님이 요청 시에만 추가).

## 배경 사진 검색어 뽑는 법

`tools/fetch_bg_image.py --query "..."`의 검색어는 슬라이드 내용에서 시각적으로 연상되는 구체적 명사 2~3개로 (예: "우주" 대신 "starry night sky galaxy"). 검색어가 너무 추상적이면 관련 없는 결과가 나온다.

## 완료 후

카드 스크립트 → `templates/README.md` 순서대로 조립 → 캡션과 함께 검수 링크 전송 (`pipeline` 상위 계획 문서 `magical-giggling-mango.md` 참고).
